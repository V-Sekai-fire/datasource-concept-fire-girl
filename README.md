# datasource-concept-fire-girl

Concept images of an avatar character in an orange dress, generated by a text-to-image diffusion model and kept with their prompts.

## What it is for

Each generated image sits beside a JSON record of the prompt, negative prompt and sampler settings that produced it. Edited copies and screenshots from an avatar maker show where the concept went next. A portable image browser is bundled for looking through them.
